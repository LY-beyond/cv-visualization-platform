# 答辩材料

> 本文件用于课程大作业答辩：架构说明、内容对照、演示脚本与常见问题。

## 1. 项目定位

《计算机视觉》交互式教学可视化平台，围绕课程课件组织“知识点讲解 + 可交互案例 + 模型训练与对比”三段式内容，覆盖第 1 至第 6 章，全部资源本地化，可在断网环境完整演示。

## 2. 技术架构

```text
┌──────────────────────────── 浏览器 ────────────────────────────┐
│ React 18 + TypeScript + Tailwind + ECharts                     │
│ 章节页（讲解/公式/对比表/结构图） + 案例工作台 + 训练面板        │
└───────────────┬────────────────────────────────────────────────┘
                │ /api（JSON，SSE 推送训练指标）
┌───────────────▼────────────────────────────────────────────────┐
│ FastAPI + Pydantic v2                                           │
│ 路由层：datasets / models / training / inference / cases        │
│ 注册表：数据集、模型、案例统一登记，新增不改动框架               │
│ 计算层：OpenCV / scikit-learn / PyTorch                         │
│ 存储层：storage/datasets、storage/assets、storage/results       │
└─────────────────────────────────────────────────────────────────┘
```

- **案例契约**：`BaseCase.execute(params, image) -> CaseOutput`，输出统一为
  `images / overlay / charts / steps / metrics / message`。
- **训练闭环**：训练任务后台线程执行，SSE 推送指标；评估结果落盘到
  `storage/results/<task_id>/`，供第 3 章的模型对比、混淆矩阵、特征嵌入直接复用。
- **离线兜底**：无外部 CDN；数据集小样本、课件结构图、评估结果均在本地。
- **前端构建托管**：`npm run build` 后，FastAPI 在 `/app` 下托管构建产物，单进程即可演示。

## 4. 平台亮点

1. **内容与课件一致**：章节讲解、公式、对比表、结构图均依据课件整理；结构图直接从课件 PDF 提取。
2. **真实计算而非截图**：通道、LBP、SIFT、HOG、RANSAC、分割、检测、识别等案例均由后端实时计算返回。
3. **训练结果复用**：第 3 章模型对比、混淆矩阵、错误样例、特征嵌入读取真实训练评估，形成“训练—评估—分析”闭环。
4. **演示稳定**：无外网依赖，示例输入内置；关键案例在无训练结果时自动回退到示例数据并提示。
5. **体验完整**：浅色/深色主题、移动端抽屉导航、图表随主题切换。

## 5. 演示脚本（约 8 分钟）

1. **首页（30 秒）**：介绍课程覆盖、技术栈与“讲解—案例—训练”三段式结构。
2. **第 1 章（1 分钟）**：展示发展时间线与方法对比表，说明传统与深度方法的差异。
3. **第 2 章（1.5 分钟）**：拖动通道查看参数；演示 LBP 编码与 HOG 梯度直方图。
4. **第 2 章实例（1.5 分钟）**：特征匹配连线 → RANSAC 剔除误匹配 → 拼接结果。
5. **第 3 章（2.5 分钟）**：
   - 切换训练曲线回放，观察 Loss/Acc 变化；
   - 模型对比面板展示 SVM / LeNet-5 / BoW / K-Means 的准确率与混淆矩阵；
   - 混淆矩阵与错误样例定位易混类别；
   - 特征嵌入投影切换 PCA / t-SNE，观察类别可分性。
6. **第 4/5/6 章（1.5 分钟）**：各选 1 个代表案例，覆盖分割、检测、识别三条主线。
7. **收尾（30 秒）**：切换深色模式，说明离线部署与扩展入口。

## 6. 常见问题

**Q：为什么第 3 章部分案例显示“示例数据”？**
A：平台优先读取本机真实训练评估；若尚未训练，会使用内置示例并明确标注，保证课堂演示不断档。完成一次训练后刷新即切换为真实结果。

**Q：案例计算会不会很慢？**
A：多数案例在百毫秒级；t-SNE 特征嵌入约 1~2 秒。参数变化有防抖，避免频繁计算。

**Q：如何新增一个案例？**
A：后端案例实现 `BaseCase` 并在 `implementations.py` 登记；纯前端案例在 `frontend/src/cases/registry.tsx` 登记组件，章节页自动出现。

**Q：平台是否依赖网络？**
A：不依赖。数据集、结构图、训练结果与前端构建产物均可本地部署，断网可用。
