## 0. 一页纸结论

1. **平台现有模型的时间跨度是 1998–2020**：LeNet-5(1998)、AlexNet(2012)、VGG-16(2014)、Faster R-CNN(2015)、FaceNet(2015)、ResNet-50(2015)、Mask R-CNN(2017)、YOLOv3(2018)、ViT(2020)。这套组合完整覆盖了"经典深度学习"脉络，但确实缺少 **2021 年之后**的内容。
2. **近三年计算机视觉的三条主线**：
   - **基础模型化**：一个骨干（DINOv3、SAM 3、VGGT、Qwen3-VL）替代"一任务一模型"，下游靠提示或轻量适配。
   - **架构混合化**：纯 CNN / 纯 Transformer 之争结束，CNN + Attention + **Mamba 状态空间** 混合成为效率新解（MambaVision、VMamba、VideoMamba、MambaIRv2）。
   - **生成统一化**：扩散（DiT/FLOW）与自回归（VAR）两条路线在图像、视频、3D 上统一，"生成 + 理解"走向同一个多模态模型。
3. **推荐优先补进平台的 6 个内容**（成本低、课堂说服力强）：
   | 优先级 | 内容 | 理由 | 接入成本 |
   | --- | --- | --- | --- |
   | P0 | ResNet → ConvNeXt V2 → ViT → DINOv3 四代骨干对照 | 直接回应"模型旧"，一条时间线讲完十年演进 | 低（结构图 + 指标卡） |
   | P0 | YOLOv3 → YOLOv12/v13、Faster R-CNN → DETR/D-FINE/DEIMv2 两条检测路线 | 课件检测章的最佳升级点 | 中（模型卡 + 预计算结果） |
   | P0 | SAM → SAM 2 → SAM 3 提示式分割演进 | "分割范式变了"最有冲击力 | 低（讲解 + 预计算掩膜） |
   | P1 | 自监督：MAE → DINOv2 → DINOv3 / V-JEPA 2 | 解释"为什么现在不用 ImageNet 标签" | 低（对比表 + 特征可视化） |
   | P1 | 扩散生成：DDPM → LDM → DiT → FLUX / VAR | 补齐课件几乎空白的生成方向 | 中（采样步数动画） |
   | P1 | 3D：NeRF → 3DGS → VGGT 前馈重建 | 与第 8 章多目视觉天然衔接 | 中（预渲染视频/点云） |

## 1. 与平台现有模型的逐项对照

| 方向 | 平台现有模型（年份） | 最新代表（年份 / 出处） | 关键跃迁（一句话） |
| --- | --- | --- | --- |
| 分类骨干 | LeNet-5 (1998)、AlexNet (2012)、VGG-16 (2014)、ResNet-50 (2015)、ViT (2020) | ConvNeXt V2 (CVPR 2023)、EVA-02 (2023)、MambaVision (CVPR 2025)、DINOv3 (2025) | 从"堆卷积/堆注意力"到"自监督预训练 + 混合架构"，ImageNet 不再是唯一评测场 |
| 传统分类 | BoW + SVM、KMeans、SVM | 仍保留作对照 | 传统方法退为"特征工程"教学基线，工业界已被端到端取代 |
| 目标检测 | YOLOv3 (2018)、Faster R-CNN (2015) | YOLOv12/v13 (2025)、D-FINE (ECCV 2024)、DEIM/DEIMv2 (CVPR 2025 / 2025)、RT-DETRv2~v4 (2024–2025) | 单阶段走向"注意力 + 分布回归"，DETR 系从"慢而准"变成"实时且准" |
| 实例分割 | Mask R-CNN (2017) | Mask2Former (CVPR 2022)、SAM (2023)、SAM 2 (2024)、SAM 3 (ICLR 2026) | 从"逐实例出掩膜"到"任意提示分割 + 视频记忆 + 概念提示" |
| 人脸识别 | FaceNet (2015) | ArcFace (CVPR 2019)、AdaFace (CVPR 2022)、TransFace (ICCV 2023)、SapiensID (2025) | 损失函数从 Triplet 转向角度间隔，骨干转向 Transformer/基础模型 |
| 跟踪 | 平台为卡尔曼滤波演示 | ByteTrack (ECCV 2022)、OC-SORT (CVPR 2023)、MOTIP (CVPR 2025)、SAMURAI (2024)、SAMURAI++ (CVPR 2026 Findings) | 从"检测 + 卡尔曼"到"检测 + 查询/记忆"，再到"分割即跟踪" |
| 多目 / 3D | 平台为双目深度演示 | NeRF (2020)、3DGS (SIGGRAPH 2023)、VGGT (CVPR 2025 最佳论文)、DUSt3R/MASt3R (2024) | 从"逐场景优化"到"一次前向出相机+深度+点云" |
| 视觉问答 | 平台为图文对齐演示 | LLaVA (2023)、Qwen2.5-VL (2025)、InternVL3 (2025)、Qwen3-VL (2025) | 从"对齐打分"到"通用多模态对话 + 视觉推理" |
| 生成 | 平台未覆盖 | DDPM (2020)、LDM (CVPR 2022)、DiT (ICCV 2023)、SD3.5、FLUX.1、VAR (NeurIPS 2024 最佳论文) | 从"像素扩散"到"潜空间流匹配 / 下一尺度预测" |
| 轻量化 | 平台未覆盖 | MobileNetV4 (ECCV 2024)、RepViT (CVPR 2024)、EfficientViT | 移动端精度-延迟帕累托前沿被反复刷新 |

> **答辩话术**：不是说旧模型错了，而是"课件讲的是方法的**起源**，平台负责补上它的**现在**"。每个方向给出 1 张演进时间线，比罗列 50 篇论文更有效。

## 2. 分方向详解

### 2.1 图像分类与骨干网络

**演进时间线**：LeNet-5 (1998) → AlexNet (2012) → VGG (2014) → ResNet (2015) → ViT (2020) → ConvNeXt V2 (2023) → EVA-02 (2023) → VMamba / MambaVision (2024–2025) → DINOv3 (2025，骨干即基础模型)。

| 模型 | 年份 / 出处 | 核心创新 | 教学价值 |
| --- | --- | --- | --- |
| ConvNeXt V2 | CVPR 2023 | 全卷积现代化改造 + **FCMAE 掩码自编码预训练** + GRN 归一化，纯 ConvNet 追平 Transformer | 证明"卷积没过时"，与 ViT 形成完美对照 |
| EVA-02 | 2023 | 用 MIM 预训练 + 蒸馏，TrV 块（SwiGLU、2D RoPE、Sub-LN） | 讲"预训练范式"如何决定上限 |
| VMamba | NeurIPS 2024 | 十字扫描模块 CSM，把 2D 图像变成 1D 序列做线性复杂度建模 | Mamba 入门首选，复杂度 O(N) 对比注意力 O(N²) |
| MambaVision | CVPR 2025 | 前两阶段 CNN、后两阶段 Mamba + Transformer 混合；重设计 Mamba 以增强全局上下文 | 讲"混合架构"为何成为效率新解 |
| DINOv3 | 2025（Meta，arXiv 2508.10104） | 数据/模型双 scaling + **Gram anchoring** 解决长训练下稠密特征退化；7B 参数 | 一句话：骨干网络已经变成"不用微调也能做分割/深度"的基础模型 |
| MobileNetV4 | ECCV 2024 | Universal Inverted Bottleneck（UIB）+ Mobile MQA 注意力 | 移动端部署章节的现成素材 |
| RepViT | CVPR 2024 | 用 ViT 视角重构 MobileNetV3，纯轻量 CNN 取得更低延迟 | 讲"结构重参数化 + 架构搜索" |

**顶会/顶刊**：CVPR 2023–2025、ECCV 2024、NeurIPS 2024；综述可参考 TPAMI 上的视觉骨干综述（检索关键词 "vision backbone survey TPAMI"）。

**平台接入建议**：在 ch3 增加一条横向"骨干演化带"，点击每个节点弹出结构图 + 参数量 + 年份；不需要训练。

### 2.2 自监督与视觉基础模型

**演进时间线**：SimCLR/MoCo (2020) → MAE (CVPR 2022) → DINOv2 (2023–2024) → I-JEPA (CVPR 2023) → V-JEPA 2 (2025) → DINOv3 (2025)。

| 模型 | 年份 / 出处 | 核心思想 | 关键结论 |
| --- | --- | --- | --- |
| MAE | CVPR 2022 | 随机遮挡 75% 图块，重建像素 | 证明"掩码重建"可替代对比学习 |
| DINOv2 | 2023（TMLR 2024） | 自蒸馏 + 大规模精选数据，无需标签 | 特征开箱即用，linear probe 即 SOTA |
| I-JEPA | CVPR 2023 | 在**特征空间**预测被遮挡区域，而非重建像素 | 引出"世界模型"路线 |
| V-JEPA 2 | 2025（Meta，arXiv 2506.09985） | 视频自监督 + 少量交互数据后训练，可用于**零样本规划** | 自监督特征可驱动机器人规划 |
| V-JEPA 2.1 | 2026（arXiv 2603.14482） | Dense Predictive Loss，兼顾稠密特征与全局理解 | 视频自监督开始补齐"稠密预测"短板 |
| DINOv3 | 2025 | Gram anchoring + 大规模蒸馏 | 稠密任务（分割/深度）不再必须微调 |

**教学价值**：这是回答"为什么 ImageNet 预训练不再重要"的最佳章节。可在 ch1/ch3 增加 2 分钟动画：同一张图，MAE 重建像素 vs I-JEPA 预测特征 vs DINOv3 直接出分割。

### 2.3 目标检测

课件讲的是 **两阶段（Faster R-CNN）+ 单阶段锚框（YOLOv3）** 的 2015–2018 范式。2023 年后有两条清晰新路线：

**路线 A：YOLO 系列持续迭代（工程影响最大）**

| 模型 | 年份 / 出处 | 关键点 |
| --- | --- | --- |
| YOLOv8 / YOLO11 | Ultralytics 2023 / 2024 | 工程化集大成，无正式论文，工业界事实标准 |
| YOLOv12 | 2025（arXiv 2502.12524） | **注意力中心**的实时检测器，在保持速度的同时引入注意力 |
| YOLOv13 | 2025（arXiv 2506.17733） | **HyperACE** 超图自适应关联增强 + 全流程特征分发，建模高阶跨位置/跨尺度相关 |
| YOLO26 | Ultralytics 2025 发布 | 边缘优先、去 NMS 的工程版本，**⚠️ 无同行评审论文**，仅作趋势参考 |

**路线 B：DETR 系从"收敛慢"到"实时最强"**

| 模型 | 年份 / 出处 | 关键点 |
| --- | --- | --- |
| DETR | ECCV 2020 | 集合预测，去掉锚框与 NMS，但收敛极慢 |
| RT-DETR | CVPR 2024 | 首个实时 DETR，混合编码器 + IoU 感知查询选择 |
| RT-DETRv2 | 2024（arXiv 2407.17140） | 训练策略与查询初始化改进，更易部署 |
| D-FINE | ECCV 2024（arXiv 2410.13842） | **细粒度分布回归 FDR + 全局最优自蒸馏 GO-LSD**；L/X 在 COCO 上 **54.0 / 55.8 AP，T4 上 124 / 78 FPS** |
| DEIM | CVPR 2025（arXiv 2412.04234） | 改进匹配（Dense O2O + Matchability-Aware Loss），**一半训练轮数**即超过 RT-DETRv2 / D-FINE |
| DEIMv2 | 2025（arXiv 2509.20787） | 引入 **DINOv3** 特征 + 轻量 STA，DEIMv2-X 达 **57.8 AP**，参数量显著少于同级大模型 |
| RT-DETRv4 | 2025（arXiv 2510.25257） | 用视觉基础模型"无痛"增强实时检测，聚焦 VFM 特征与 DETR 的结合 |

**开放词汇检测**：Grounding DINO（ECCV 2024）用文本提示检测任意类别，是"检测也能零样本"的代表。

**平台接入建议**：ch5 加一个"三代检测器对比"页：
- 第一代：Faster R-CNN（两阶段、RPN、RoIAlign）
- 第二代：YOLOv3（锚框 + 多尺度）
- 第三代：D-FINE / DEIM（无锚框、分布回归、端到端）
用同一张实验五的街景图，展示"候选框数量 / 是否需要 NMS / 单图耗时"的差异。

### 2.4 图像分割（含提示式分割）

**演进时间线**：FCN (2015) → U-Net (2015) → DeepLab 系列 → SegFormer (2021) → Mask2Former (2022) → SAM (2023) → SAM 2 (2024) → SAM 3 (ICLR 2026)。

| 模型 | 年份 / 出处 | 核心创新 |
| --- | --- | --- |
| SegFormer | NeurIPS 2021 | 分层 Transformer 编码器 + 极轻量 MLP 解码器 |
| Mask2Former | CVPR 2022 | 掩码分类统一语义/实例/全景分割 |
| OneFormer | CVPR 2023 | 一次训练、任务可切换的统一分割 |
| SAM | ICCV 2023 | **提示式分割**：点/框/掩膜提示，SA-1B 11 亿掩膜 |
| EfficientSAM | CVPR 2024 | 蒸馏 SAM，轻量化 |
| FastSAM | 2023 | YOLOv8 分割一切，速度优先 |
| SAM 2 | 2024（Meta，arXiv 2408.00714） | 流式记忆 + 视频分割；图像分割比 SAM **更准且快 6 倍**，视频交互次数少 3 倍 |
| SAM 3 | ICLR 2026（arXiv 2511.16719） | **概念提示分割（PCS）**：短名词短语 / 图像样例即可分割并给出唯一实例 ID，统一检测+分割+跟踪 |
| SAM2MOT | AAAI 2025（arXiv 2504.04519） | 把 SAM2 直接变成多目标跟踪器，零样本跨数据集 |

**教学价值**：SAM 系列是"分割从任务模型变成基础模型"的分水岭，且演示直观（点一下出一个掩膜），非常适合课堂录屏。SAM 3 的"概念提示"还能自然引出开放词汇分割。

### 2.5 图像生成与 3D 生成

**图像生成时间线**：GAN (2014) → DDPM (2020) → LDM / Stable Diffusion (CVPR 2022) → DiT (ICCV 2023) → SD3 (2024) → FLUX.1 (2024) → SD3.5 / FLUX.1 Kontext (2025) → VAR (NeurIPS 2024 最佳论文)。

| 模型/方法 | 年份 / 出处 | 关键点 |
| --- | --- | --- |
| DDPM | NeurIPS 2020 | 去噪扩散概率模型，奠定生成范式 |
| LDM / Stable Diffusion | CVPR 2022 | 把扩散搬到**潜空间**，算力门槛骤降 |
| DiT | ICCV 2023 | 用 Transformer 替换 U-Net，可扩展性大幅提升 |
| SD3 | 2024（arXiv 2403.03206） | MMDiT + **Rectified Flow** 流匹配 |
| SD3.5-Flash | 2025（arXiv 2509.21318） | 分布引导蒸馏，少步出图 |
| FLUX.1 | 2024（Black Forest Labs） | 12B 级流匹配 Transformer，文生图质量标杆；架构解析见 arXiv 2507.09595 |
| FLUX.1 Kontext | 2025（arXiv 2506.15742） | 生成与**编辑统一**在同一流匹配模型中 |
| VAR | NeurIPS 2024 **最佳论文** | "下一尺度预测"替代"下一 token 预测"，自回归生成首次在 ImageNet 上超越扩散 |

**3D 生成**：

| 模型 | 年份 / 出处 | 关键点 |
| --- | --- | --- |
| TRELLIS | 2024（Microsoft，arXiv 2412.01506） | 结构化 3D 潜变量 SLat，统一文本/图像到 3D |
| Hunyuan3D 2.0 | 2025（腾讯，arXiv 2501.12202） | 形状 DiT + 纹理 DiT 两阶段，高分辨率带纹理资产 |

**平台接入建议**：生成方向平台目前空白。最低成本做法是"采样过程动画"：用固定随机种子，把 DDPM 的 1000→0 步、流匹配的 10 步、VAR 的 1→256→512 尺度三段过程并排播放。不需要跑大模型。

### 2.6 视频生成与视频理解

**视频生成（2024–2026，开源阵营已追平闭源）**：

| 模型 | 年份 / 出处 | 关键点 |
| --- | --- | --- |

| Veo 3 / Sora 2 | Google / OpenAI，2025 | 闭源工业标杆，**⚠️ 无公开技术论文**，只作趋势引用 |

**视频理解**：

| 模型 | 年份 / 出处 | 关键点 |
| --- | --- | --- |
| InternVideo2 | ECCV 2024（arXiv 2403.15377） | 掩码建模 + 跨模态对比 + 下一 token 预测三阶段统一，编码器扩到 6B |

### 2.8 3D 视觉：NeRF → 3D Gaussian Splatting → 前馈重建

| 模型 | 年份 / 出处 | 关键点 |
| --- | --- | --- |
| NeRF | ECCV 2020 | 隐式辐射场 + 体积渲染，质量标杆但训练慢 |
| Instant-NGP | SIGGRAPH 2022 | 哈希编码，训练从小时级降到分钟级 |
| 3DGS | SIGGRAPH 2023 | 显式 3D 高斯 + 光栅化，**实时**渲染 |
| 2DGS | SIGGRAPH 2024 | 2D 高斯面元，几何重建更准 |
| Mip-Splatting | CVPR 2024 | 多尺度抗锯齿，解决 3DGS 缩放闪烁 |
| DUSt3R | CVPR 2024 | 无相机参数的**点图回归**，两视图直接出 3D |
| MASt3R | ECCV 2024 | DUSt3R + 匹配头，稀疏视图重建与定位 |
| VGGT | **CVPR 2025 最佳论文**（arXiv 2503.11651） | 一次前向，从数百视图直接出相机参数、深度、点云、跟踪；前馈替代逐场景优化 |

**平台接入建议**：ch8 多目视觉是最佳落点。
- 低成本：放 3DGS 预渲染的环绕视频（左右拖动旋转），对比 NeRF 的慢速渲染。
- 中成本：用 VGGT 对实验二的拼接图对做一次前馈重建，展示"不需要标定也能出点云"。

**综述**：*Advances in Feed-Forward 3D Reconstruction and View Synthesis: A Survey*（arXiv 2507.14501）可作为课程拓展阅读。

## 5. 平台接入方案（按成本分三档）

### 5.1 三档策略

| 档位 | 做法 | 适合对象 | 是否改后端 |
| --- | --- | --- | --- |
| **A. 展示型** | 模型卡 + 演进时间线 + 指标表 + 官方结构图 | DINOv3、SAM 3、Qwen3-VL、VGGT、FLUX | 否，纯前端数据 |
| **B. 预计算型** | 离线跑一次推理，存图/JSON，前端回放 | SAM 2/3 掩膜、DEIMv2 检测框、VGGT 点云、3DGS 环绕视频 | 否 |
| **C. 在线推理型** | 小模型转 ONNX，浏览器/服务端实时推理 | MobileNetV4、ConvNeXt V2-T、EfficientViT、YOLOv12n | 是（已有 ONNX 管线） |

**判定规则**：权重 > 20MB 一律走 B；≤ 20MB 且输入固定（224/256/512）才考虑 C。这条规则平台已有先例（LeNet 纯 JS、ResNet18 量化），继续沿用即可。

### 5.2 章节映射

| 章节 | 现有内容 | 建议补充 | 档位 |
| --- | --- | --- | --- |
| ch1 概述 | 视觉任务总览 | "2026 年视觉版图"一页图：基础模型 / 生成 / 3D / 具身四条主线 | A |
| ch2 基础 | 滤波、边缘、SIFT | 传统算子 → 学习型复原（SwinIR / MambaIR）一句话衔接 | A |
| ch3 分类 | LeNet~ViT、12 模型 | 骨干演化带 + ConvNeXt V2 / DINOv3 模型卡；MobileNetV4 在线推理 | A + C |
| ch4 分割 | FCN、Mask R-CNN | SAM → SAM 2 → SAM 3 三代演示（点提示分割 + 视频记忆） | B |
| ch5 检测 | Faster R-CNN、YOLOv3 | 三代检测器对比页（RPN / Anchor / 分布回归），DEIMv2 预计算结果 | B |
| ch6 识别 | FaceNet | 度量学习损失演化图（ArcFace → AdaFace → TransFace） | A |
| ch7 跟踪 | 卡尔曼 | 三代跟踪对比（SORT / MOTIP / SAMURAI） | A + B |
| ch8 多目 | 双目深度 | NeRF → 3DGS → VGGT 时间线；3DGS 环绕视频 | B |
| ch9 VQA | 图文对齐 | 三代 VQA + Qwen3-VL 预计算问答回放 | A + B |

### 5.3 推荐新增的 8 个低成本案例

| # | 案例 | 交互 | 数据来源 | 成本 |
| --- | --- | --- | --- | --- |
| 1 | 骨干演化带 | 时间轴滑动，切换模型结构图与指标 | 官方论文图（重绘） | 低 |
| 2 | SAM 点提示分割 | 图上点击 → 显示掩膜（预计算 6~8 个点） | SAM 2 官方 demo 离线结果 | 低 |

| 4 | 扩散采样过程 | 步数滑杆 0→50，播放去噪帧 | SD3.5/FLUX 固定种子离线采样 | 中 |
| 5 | VAR 尺度生成 | 1→16→64→256 token 图逐级放大 | VAR 官方 demo 离线帧 | 中 |

### 5.4 不建议接入的内容

- **Sora 2 / Veo 3**：无公开论文与权重，只有宣传视频，学术上无法复现。
- **GPT-5 / Gemini 2.5 级别闭源模型**：无法离线演示，且与课程知识点关联弱。
- **π0 / OpenVLA**：需要机器人硬件，作为"展望"提及即可。
- **超大 3D 生成模型**：推理成本高，演示价值不如 3DGS 环绕视频。

## 6. 答辩可直接使用的一段话

> "课件里的 LeNet、AlexNet、ResNet、YOLOv3 讲的是方法的起源，这个不能删。但 2023 年以后计算机视觉发生了三件事：第一，骨干网络变成了基础模型，DINOv3 不微调就能做分割和深度；第二，分割和检测被提示式范式重构，SAM 3 用一句名词短语就能分割并跟踪；第三，生成和理解在同一个多模态模型里合流，Qwen3-VL 既能问答也能定位。我们在平台上给每个方向补了一条演进时间线和最新模型卡，并优先接入了能在浏览器里跑或能离线预计算的部分，保证断网也能演示。"

### 9.11 使用与合规提醒

1. **许可证差异大**：ConvNeXt、D-FINE、DEIM、YOLOv12/v13 多为 Apache-2.0 / MIT；SAM 系列、DINOv3、VGGT 属研究许可，部分限制商用。课程演示可用，但文档与页面须标注来源与许可证。
2. **权重体积决定接入方式**：>20MB 一律预计算；≤20MB 且输入尺寸固定才考虑 ONNX 浏览器推理。
3. **版本会漂移**：上述仓库多为主线分支，接口随版本变化。复现实验时应锁定 commit 或 tag，并在平台文档中记录版本号。
4. **不要直接复制论文指标**：不同仓库的评测脚本、分辨率、预训练数据不一致，跨模型比较需统一口径（如统一 224×224、统一 COCO val2017）。
