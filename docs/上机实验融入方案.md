# 上机实验内容融入开发方案

> 依据：课程五次上机实验（任务书 + 学生实验报告 + 代码 + 结果素材，位于 `实验项目/`），以及教师"大作业可视化平台最好能够加入平时上机实验的内容和模型"的要求。
> 目标读者：本项目开发者。本文档是实施规格，按阶段执行即可，不需要再补调研。

---

## 一、目标与原则

### 1.1 目标

把五次上机实验的**内容、数据、结果与模型**融入现有可视化平台，使平台从"算法演示站"升级为"课程学习 + 实验档案 + 在线推理"一体化平台：

1. 每次上机实验在网站上有完整档案：实验目的、任务、原理、真实实验数据、结果图、思考题与结论。
2. 实验中交互性强的知识点变成可操作案例，挂入对应章节，与现有 42 个案例同一套信息骨架。
3. 实验训练出的模型（LeNet、ResNet18 等）接入模型库，能在线推理或展示真实推理结果。
4. 实验报告中的定量结果（特征对比、PSNR、训练曲线、检测器对比）用 ECharts 在网页端复现，而非只贴静态图。

### 1.2 原则

- **双轨融入**：章节侧加"交互案例"，另设"实验中心"承载完整实验档案，二者互相跳转，不重复建设。
- **真实数据优先**：报告中的实测数字（准确率、PSNR、耗时、IoU）一律保留原值并标注来源，不伪造、不四舍五入成"漂亮数"。
- **离线可用**：全部素材本地化，不出现运行时外链；遵循现有离线资源扫描测试。
- **复用现有架构**：新案例走 `case_registry` + `CaseOutput` + `CaseFrame`；新模型走 `ModelMeta`；前端推理走 `frontend/src/inference/*`；教学文案走 `cases/guidance.ts`；学习路径走 `learningPath.ts`。
- **大模型不进浏览器**：超过 20MB 的权重不做前端推理，用"模型卡 + 预计算推理结果"呈现。

## 三、总体设计

### 3.1 双轨结构

```
轨道 A：章节案例（交互）                轨道 B：实验中心（档案）
ch2  ─ 滤波对比/四算子/…        ┐
ch3  ─ BoVW 对比/LeNet 推理     │      /labs            实验总览（5 张实验卡）
ch4  ─ MeanShift/SLIC/Canny/…  ├────→ /labs/:labId     实验详情（报告+数据+画廊+模型）
ch5  ─ Anchor/NMS/Letterbox/…  │            ↑ 双向链接：案例页"来自实验N" ↔ 档案页"动手试试"
                                ┘
```

- 案例页右上角新增来源徽标"上机实验 N"，点击跳到对应实验档案的关联小节。
- 实验档案中每个知识点卡片带"动手试试"按钮，跳到对应案例或模型页。

### 3.2 实验中心信息架构

新增路由：

| 路由 | 页面 | 内容 |
| --- | --- | --- |
| `/labs` | 实验总览 | 5 张实验卡片：编号、主题、日期、知识点标签、结果图封面、关联案例/模型数 |

## 四、详细设计

### 4.1 素材迁移与静态托管

所有实验素材复制到前端静态目录，保持离线可访问：

```
frontend/public/labs/
  lab1/  report.html（docx 转 HTML，保留图）  images/*.png
  lab2/  report.html（md 渲染，公式走 KaTeX）  images/*.png
  lab3/  bow/ report.html + results 精选图 + 对比 CSV 转 JSON
         lenet/ report.html + 曲线/混淆矩阵/误判图 + web-results 精选
         cifar100/ report.html + 曲线 + 误判图 + classes.json
  lab4/  report.html + ex1~ex6 精选图 + slic/loop0~9 迭代帧 + fcn 曲线
  lab5/  report.html + 检测/分割结果图 + predictions/*.json + 对比数据
```

迁移规则：

1. **报告转 HTML**：docx 用 pandoc 或 mammoth 转 HTML；md 报告在前端用现有 Markdown + KaTeX 渲染（与章节公式同一套组件）；ipynb 用 jupyter nbconvert 转 HTML。统一套站内样式（Tailwind typography），去掉绝对路径，图片改相对路径。
2. **图片精选**：实验1 全量 39 张；实验2 全量 36 张；实验4 精选约 40 张 + SLIC 迭代帧全保留（做播放器）；实验3/5 保留报告引用图与推理结果图。单张图压缩到宽 1600 以内，总体积控制在 60MB 内。
3. **结构化数据**：报告中的关键表格转为 `frontend/src/data/labs/*.ts`（或 public 下 JSON），供 ECharts 与表格组件使用，字段与报告数值严格一致。
4. **大权重不复制进前端**：Faster R-CNN / Mask R-CNN / YOLO v3 三份权重（合计约 640MB）保留在 `实验项目/` 原处，网站只登记其元信息与预计算结果；如需服务端推理，由后端按绝对路径加载（见 4.5）。

### 4.2 实验档案数据结构

新增 `frontend/src/data/labs/types.ts`：

```ts
export interface LabSection {
  id: string;                 // 锚点 id
  title: string;
  html?: string;              // 报告小节 HTML（静态导入）
  caseIds?: string[];         // 关联交互案例 → "动手试试"
  modelIds?: string[];        // 关联模型
}
export interface LabChart {
  sectionId: string;
  title: string;
  source: string;             // 数据来源说明，如"实验二报告 表3.2.3"
  kind: "bar" | "line" | "table" | "scatter";
  data: unknown;              // 按 kind 约定的数据结构
}
export interface LabGalleryItem {
  sectionId: string; src: string; caption: string;
}
export interface LabMeta {
  id: string;                 // lab1..lab5
  title: string;              // 上机实验一 · 图像基础操作
  date: string;
  cover: string;
  tags: string[];
  summary: string;            // 实验目的与结论摘要
  sections: LabSection[];
  charts: LabChart[];
  gallery: LabGalleryItem[];
  thoughtQuestions: { q: string; a: string }[];   // 思考题折叠卡
}
```

五次实验各一份 `lab1.ts ~ lab5.ts`，`index.ts` 汇总。数值全部取自报告原文，例如：

- lab2：`filterPsnr`（6 种滤波 PSNR：23.31 / 24.79 / 24.40 / 32.00 / 29.88 / 28.32）、`edgeOperatorStats`（Roberts 95.52%/7.57 等四行）、`siftBenchmark`（自实现 1089 点 4~6s vs OpenCV 1011 点 0.04~0.06s）。
- lab3：`bowFeatureCompare`（HOG 0.6905 / 稠密SIFT 0.6571 / SIFT 0.5571 / LBP 0.4762 / ORB 0.4286，联合 SIFT+HOG 0.7238）、`lenetEpochs`（5 轮 loss/acc + 测试 0.9812）、`lenetPlusCompare`（98.12% vs 98.48%，参数 61,706 vs 33,706）、`cifar100Epochs`（3 轮四项指标 + 教师 200 轮 75.85%/92.97%）。
- lab4：`meanShiftRadius`（radius 1~8 → 中心数序列）、`slicStats`（K=200/300/500/1000 四行）、`cannyParams`（sigma 与双阈值两个表）、`fcnMetrics`（FCN32/16/8 的 pixelacc 与 MeanIoU）。
- lab5：`detectorCompare`（四模型参数量/CPU 耗时/验证范围）、`nightSceneCompare`（Faster R-CNN vs YOLO v3 阈值对照）、`yoloLossParts`（loss_x/y/w/h/conf/cls 分解）。

### 4.4 模型接入一：LeNet 手写数字在线识别（前端 ONNX 推理）

复用现有 `frontend/src/inference/*`（ONNX Runtime Web + manifest 降级）：

1. **转换**：`实验项目/第三次上机实验/上机练习2/lenet/pretrained/LeNet-teacher.keras`（0.7MB）→ ONNX（tf2onnx，opset 13），输出 `frontend/public/models/lenet-mnist/model.onnx` + `manifest.json`（input 1×28×28×1、labels 0~9、preprocess 说明）。
2. **模型注册**：`backend/app/models/builtin.py` 的 `lenet5` 条目补充 `weight_path="lenet-mnist/model.onnx"`、`preprocess`（灰度、28×28、/255、黑底白字）、`metrics`（教师模型测试准确率；学生 5 轮模型 test_accuracy 0.9812 作注释）。
3. **推理页**：ch3 新增"手写数字识别"面板：
   - 画板（Canvas 28×28 逻辑分辨率，鼠标/触摸书写，笔画加粗居中）；
   - 两种预处理与实验报告一致："MNIST 原图（直接缩放）"与"自动整理笔画"（反色→二值化→外接框裁剪→等比 20×20→居中 28×28），用 TypeScript 实现，预处理前后图并排显示；
   - 输出 top-3 概率条 + "高概率不等于正确"教学提示（引用实验3 报告中 99.87% 误判案例）。
4. **上传识别**：支持上传图片走同一预处理管线，与画板共用。
5. **对照展示**：并列展示实验报告中 16 张真实识别结果（web-results 精选 6 张），含两张"自信误判"样本。

### 4.5 模型接入二：CIFAR100 ResNet18 与大型检测模型

**ResNet18（教师 200 轮权重，42.9MB）**：

- 转换为 ONNX 并量化到 FP16/INT8（目标 ≤ 25MB），放 `frontend/public/models/resnet18-cifar100/`。
- 预处理严格按实验报告：resize 32×32 → /255 → mean=(0.5071,0.4866,0.4409) / std=(0.2673,0.2564,0.2762) 标准化（训练均值，不能用 ImageNet 均值）。
- 输出 top-5，类别名用报告的 **100 类中文字典**；配"数据集示例 vs 普通照片"对照卡（6 张 cifar-*.png + 2 张 web-*.png 的真实预测记录），讲清 32×32 缩放、构图、背景、类别范围四项影响。
- 若量化后精度或体积不达标，降级为服务端推理接口 `/api/models/resnet18-cifar100/predict`，前端只调接口；再不行则只展示预计算结果。

**Faster R-CNN / Mask R-CNN / YOLO v3（三份官方权重，合计约 640MB）**：

- 不做在线推理。新增三条 `ModelMeta`（level="pretrained"，注明"官方 COCO 权重 · 结果展示"），`metrics` 使用实验5 实测（如 YOLO v3 dog 0.9996、Faster R-CNN 单图 1.37s 等），`structure_note` 写主干与关键组件。
- 前端模型卡点击后展示**预计算推理结果浏览器**：原图/检测图对照、类别-置信度-框坐标表（来自 predictions JSON）、掩膜像素统计（Mask R-CNN）、四检测器对比图（ECharts）。

## 七、验收标准

1. **档案完整**：五次实验各有独立档案页，包含任务、原理、真实数据、结果图、思考题；报告中的关键定量表格（BoVW 对比、滤波 PSNR、LeNet/CIFAR 训练指标、SLIC/Canny 参数表、FCN 指标、检测器对比）均以 ECharts 或表格复现，数值与报告原文一致。
2. **案例可用**：10 个新案例全部注册成功，`GET /cases` 可见；每个案例有参数面板、步骤输出、教学文案；后端契约测试通过。
3. **模型在线**：LeNet 画板手写 0~9 可识别，top-3 概率正常，两种预处理可切换且与报告描述一致；CIFAR100 top5 中文标签正确（或按降级方案展示预计算结果）。
4. **大模型展示**：三个检测模型卡可查看预计算推理结果（图 + 框表 + 掩膜统计），并标注结论边界。
5. **联动正确**：案例页与实验档案双向跳转；学习路径关卡可见新案例；实验已读进度持久化。
6. **工程约束**：前端 build 通过；后端全部测试通过（含离线资源扫描，新静态目录无 `http(s)://` 外链）；页面全部离线可访问。

## 八、风险与降级

| 风险 | 应对 |
| --- | --- |
| Keras→ONNX 转换失败或算子不支持 | 用 tf2onnx 固定 opset 13 重试；仍失败则把 LeNet 结构在 onnx 侧重建并加载权重（仅 6 万参数），最终降级为预计算识别结果展示 |
| ResNet18 量化后体积仍大或精度掉 | 降级为后端 `/predict` 服务端推理；再降级为预计算 top5 结果 + 训练曲线展示 |
| docx/ipynb 转 HTML 样式混乱 | 报告改为按 `LabSection.html` 手工整理关键小节（内容已在报告中结构化），图片走画廊，不追求整篇原样 |
| 素材体积过大 | 图片统一压缩（宽≤1600、PNG 必要保留，其余转 JPG q85）；SLIC 迭代帧仅保留 K=500/M=40 一组完整 10 帧，其余保留首尾帧 |
| 报告中外部链接（Pexels 等） | 仅保留文字署名，不保留可点击外链，满足离线扫描 |
| 真实数据被误读为平台实测 | 所有实验图表下方强制显示 `source` 来源标注；检测模型页固定显示结论边界说明 |
